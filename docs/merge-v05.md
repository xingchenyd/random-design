# v0.5 — unified independent repository

The independently created xingchenyd/random-design is the maintained repository.
It now hosts the original 40-direction reference library and 20 finished example
pages alongside the 21 fixed presets and existing procedural engine.

## What was preserved

- 227 files from hash-design commit e40a94239b50eaecf4b007af68d43237d7dded76.
- Original source, rules, examples, screenshots, briefs, five-language READMEs and MIT license.
- A SHA-256 manifest and tests against all 20 saved example hashes.
- A complete offline Git bundle of the former fork, including its additional branches.
- All 21 preset IDs, saved design JSON compatibility, procedural history, CLI, MCP and browser PPTX export.

The vendor snapshot is immutable. Changes belong in adapters and generated bundles.
The source maps were not relabelled as original xingchenyd work.

## What changed

The site offers a complete-example gallery and a 40-direction picker. It supports
bilingual browsing, searching, explicit style selection, brief/JSON download and
recent-direction avoidance. Four additional MCP tools expose the imported rules,
reproduction and an optional reference-only heuristic checker.

The 21 preset HTML renderer is now composition/2. Editorial uses a spanning
headline and divided contents spread; Swiss aligns a bottom price register;
brutalism concentrates information on one yellow field; Pop and Memphis remove
floating ornament; glass uses a unified translucent list; material styles refine
borders and lighting; New Chinese adds an original contour/river illustration.
The generator remains random-design/3. Use the matching release for older pixels.
PPTX retains its own editable slide compositions; HTML CSS is not a PPTX renderer.

## Verification scope

- Source snapshot hash integrity and 20 archived seed-to-ref mappings.
- 21 presets × 2 languages × 2 widths; 64 procedural layout combinations.
- Browser generation, saved-design import, direct selection and PPTX downloads.
- 20 migrated original HTML files are byte-exact; all load at desktop and narrow widths.
- Both languages of the reference picker, catalogue search, branch selection,
  brief/JSON export, preserved facts and recent exclusions.
- All 11 MCP tools exposed; original workflows and new reference workflows exercised
  over stdio and Streamable HTTP.

These checks do not claim aesthetic equivalence to the user's reference video,
native-device testing, desktop PowerPoint testing or live WorkBuddy/ChatGPT
account integration. Imported examples remain original demonstrations, with
their original content and attribution.
