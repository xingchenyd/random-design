# Material and reference guide

The 21 presets are original implementations informed by the user's reference video. The video is not redistributed. Their material treatment was rebuilt in v0.4.0. These are reference-informed adaptations, not pixel-identical copies of the source video.

Preserve the user's content. Apply a style through composition, type, material and a meaningful subject. A coffee cup belongs in the sample cafe, not automatically in a scientific or business deck.

| Style | Material and compositional requirement |
|---|---|
| Cyberpunk | Dark field, luminous outlines, controlled RGB title displacement, three signal-coloured menu cards. |
| Retro Terminal | Deep green CRT field, fine scanlines, compact monospaced information, thin rules. |
| Skeuomorphism | Warm directional wood grain, inset green menu board, pinned paper tags, ceramic rims and contact shadows. |
| Glassmorphism | Background colour remains visible through translucent panels; rim highlights and one soft shadow establish thickness. |
| Brutalism | Large compressed type, hard borders and decisive yellow/red information blocks. |
| Pop Art | Halftone printing, outlined lettering, speech-label copy and comic price stamps; illustration supports the product. |
| Memphis | Asymmetric, bounded rhythm using circles, waves and triangles; maintain a clear title and menu. |
| Editorial | Large serif title, fine column rules, numbered entries, quiet paper and a single circular image. |
| Swiss Style | Strict alignment, strong typographic hierarchy, spare red mark, unboxed menu rows. |
| Claymorphism | Rounded volumes with broad diffuse highlights, warm contact shadows and pastel raised cards. |
| Neumorphism | Same-colour substrate, raised and recessed rims, top-left light, paired light/dark edge shadows. |
| Y2K | Iridescent surface, chrome/gloss highlights, capsule controls and a slim desktop-window frame. |
| Pixel Art | Consistent pixel grid, integer edges, legible game-like counter scene and stepped outlines. |
| Neubrutalism | Thick outlines, offset hard shadows and independent bright cards; avoid unrelated ornaments. |
| Bauhaus | Primary-colour geometry describes one composition; circles, rectangles and triangles align to a grid. |
| Vaporwave | Sunset horizon, perspective grid and translucent retro window cards. |
| Aurora Gradient | Tall luminous curtains fade into a dark ground; quiet centred title and translucent lower cards. |
| Art Deco | Restrained brass lines, symmetric fan, stepped frames and centred hierarchy. |
| Sci-Fi HUD | Concentric instrument marks, technical rules, restrained cyan emission and amber readings. |
| Bento Grid | Unequal tiles, strong dominant block, consistent gutters and individual content roles. |
| New Chinese Style | Short vertical calligraphic title, layered landscape within a round window, paper field and restrained vermilion seal. |

Use one light direction across the subject, frame and cards. Highlights describe a rim or volume; shadows describe contact or elevation. Check rendered output at full size and at thumbnail scale. Check headings, prices, body copy and overflow on mobile. Colour-token contrast validation does not prove contrast on every translucent or gradient surface.

Websites use CSS surfaces and original SVG artwork. PowerPoint uses native text, tables and charts with SVG substrates and illustrations. Preserve those editable objects. Verify exported PPTX separately; browser CSS blur is not a native PowerPoint effect. The renderer's transparent SVG gradient stops produced black shadow disks during review; layered translucent shapes are used for portable contact shadows.

The sampling algorithm remains random-design/3. Renderer revision material/1 belongs to v0.4.0. Save JSON and the release: old JSON is still accepted, but opening it in this release adopts the new renderer. Use the original release for an exact old rendering. Fixed selection remains stable; random history is not consumed by selecting a fixed preset.
