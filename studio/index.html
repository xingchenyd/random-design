给每次表达，
一个新主题。

颜色、字体、构图与图形一起生成。选择一个方向，把它带到网页或幻灯片。

无需账号或 API 密钥。设计在浏览器内生成，历史保存在此浏览器。

准备好探索下一组方向

你的候选方向

同一份示例内容，比较视觉差异。点击放大后选择。

01 / GENERATE

连续参数生成配色；构图规则与程序图形组合成统一的视觉语言。

02 / COMPARE

筛掉精确重复与近期过近的主题。差异指标是属性比较，不代表审美评分。

03 / TAKE IT

下载网页、设计规范、SVG 或六页可编辑 PPTX。文字内容与风格分开管理。
